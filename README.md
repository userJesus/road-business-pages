# Road Business — distribuição

[Abrir o jogo](https://userjesus.github.io/road-business-pages/)

Este repositório contém somente os arquivos de distribuição pública: HTML, JavaScript/CSS minificados, mídia necessária para executar o jogo e avisos de bibliotecas de terceiros. Os arquivos originais, ferramentas, testes e histórico de desenvolvimento ficam em um repositório privado separado. Não são publicados source maps.

O JavaScript que roda no navegador é acessível ao visitante. Minificação não é criptografia nem impede engenharia reversa.
